# Financial-Analysis-Project
Financial analysis project focused on  understanding transactions trends , customers segments , regional performance , transactions status, fees, taxes , and key financial insights

## Overview
This project analyzes financial transaction data to understand transaction trends, customer segments, regional performance, transaction status, fees, and taxes.

## Objectives
- Analyze financial transactions
- Identify transaction trends
- Compare customer segments
- Analyze state-wise performance
- Understand transaction status
- Analyze fees and taxes

## Data Preparation
The raw data was cleaned and transformed using Power Query before analysis.

## Key KPIs
- Total Amount
- Total Transactions
- Average Transaction Value
- Total Fees
- Total Tax
- YoY Growth

## Dashboard
The dashboard includes:
- Monthly transaction analysis
- Transaction status analysis
- Customer segment analysis
- State-wise analysis
- Transaction type analysis
- Gender analysis
- Detailed transaction records

## Tools Used
- Power BI
- Power Query
- DAX
- CSV

- Dataset folder – Contains the datasets
